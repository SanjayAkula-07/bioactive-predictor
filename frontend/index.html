Evaluation Summary

  • Molecule-aware 10-fold cross-validation. The 70% development set was split into ten folds so that records of the same molecule never sit on both sides of a split. This keeps the scores honest instead of rewarding a model for recognising molecules it has already seen.
  • Multiple metrics. Accuracy, precision, recall, F1, ROC-AUC, F1 stability and training time each show a different side of model quality.
  • Why Mean CV F1. Active and Inactive molecules are not equally common, and both kinds of error matter, so F1 (the balance of precision and recall) was fixed as the selection criterion before comparing the models.
  • Holdout evaluation. The selected model was evaluated on the untouched holdout set, which played no part in selection: Accuracy 0.8089 · Precision 0.8202 · Recall 0.9388 · F1 0.8755 · ROC-AUC 0.8402.
  • Final selected model: XGBoost — highest Mean CV F1 (0.883443) of the six models.

About

About This Project

Problem Statement

In early-stage drug discovery, identifying bioactive compounds for disease-related targets such as Cyclooxygenase-2 (COX-2) can be time-consuming and expensive through traditional experimental methods.

What This Project Does

This project is a machine-learning-based virtual screening tool that takes a molecule's SMILES representation and uses RDKit to convert it into a 2048-bit Morgan fingerprint representing its chemical structure.

Six models — XGBoost, Random Forest, SVM, Naive Bayes, RBF, and ANN — are evaluated using molecule-aware cross-validation. The model with the highest mean F1 score is automatically selected. In our current experiment, XGBoost achieved the highest mean F1 score.

The selected model predicts whether a compound is Active or Inactive and provides a probability score to help prioritize compounds for further investigation.
